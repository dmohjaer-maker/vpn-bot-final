# VPN Bot

ربات فروش سرویس VPN با Python و aiogram.

## راه‌اندازی

1. وابستگی‌ها را نصب کنید:

   ```bash
   pip install -r requirements.txt
   ```

2. متغیرهای محیطی فایل `.env.example` را در محیط اجرا تنظیم کنید:

   - `BOT_TOKEN`: توکن ربات از BotFather
   - `ADMIN_IDS`: شناسه عددی ادمین‌ها، با کاما جداشده
   - `SUPPORT_USERNAME`: یوزرنیم پشتیبانی، اختیاری
   - `CARD_NUMBER`: شماره کارت، اختیاری
   - `CARD_HOLDER`: نام صاحب کارت، اختیاری

3. ربات را اجرا کنید:

   ```bash
   python bot.py
   ```

اطلاعات حساس داخل مخزن ذخیره نمی‌شوند. برای اجرای واقعی، مقادیر محیطی را در سرویس میزبانی تنظیم کنید.
